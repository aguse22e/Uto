# Uto

Uto — Solana meme coin launchpad. Buat token, trading, kirim dan terima SOL.

GitHub Pages: https://aguse22e.github.io/Uto/

## Tentang versi ini

Ini adalah versi statis Uto untuk GitHub Pages (satu file `index.html`).

- Feed token dari DEX Screener, detail token, dashboard setelah login, akun Admin & Pemain (lokal), frasa pemulihan 12 kata, 2FA, Kirim & Terima Solana, dan panel Connect Wallet.
- Tema luxury hitam-emas, responsif HP / tablet / desktop.

Catatan jujur: versi statis ini tidak menjalankan server. Fitur server di aplikasi Uto yang utuh — verifikasi login/2FA di server, bonding curve on-chain, graduation otomatis, dan creator fee on-chain — tidak aktif di sini. Uto tidak pernah meminta seed phrase atau private key.
